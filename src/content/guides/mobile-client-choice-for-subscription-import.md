电脑端有[现成的导入教程](/guides/clash-verge-rev-import-subscription-tutorial/)，手机端不一样：客户端更多，上架状态变得快，有的在你所在地区的商店根本搜不到。所以这篇不替你背书某一款软件，而是给出一套**怎么挑**的标准。

## 选客户端的 5 条标准

| 标准 | 为什么重要 | 怎么核对 |
| --- | --- | --- |
| 官方来源 | 客户端处理你全部网络流量 | 从项目官方页面或开发者官方渠道进入，不用第三方打包 |
| 支持订阅格式 | 不支持就读不出节点 | 商家教程页会写支持的格式，对照客户端说明 |
| 持续更新 | 协议和内核在变，长期不更新的软件会逐渐失效 | 看项目最近一次更新时间 |
| 规则分流 | 决定国内外流量能不能自动区分 | 看是否支持规则和规则集 |
| 耗电与后台稳定性 | 手机后台常被系统杀掉 | 看使用反馈，自己用一天检验 |

## iOS 的选择流程

1. 先查看你的账号所在地区，在应用商店里能搜到哪些相关客户端；
2. 按上面的 5 条标准筛选，不要因为名字熟就下载；
3. 注意不同客户端的付费方式，是一次性买断还是订阅制，下单前看清楚；
4. 在商家的使用教程页查找是否列出推荐的 iOS 客户端，优先看列出来的。

iOS 对后台网络扩展有系统限制，不同客户端的省电表现不同，需要自己试用观察。

## 安卓的选择流程

1. 先看商家教程推荐了哪些客户端；
2. 打开项目官方发布页，看最近更新时间和发布说明；
3. 下载与你设备架构匹配的安装包，通常是 arm64；
4. 安装后给予 VPN 连接权限，并把应用加入省电白名单，防止被后台清理。

## 导入订阅的通用步骤

不论哪个客户端，基本都是这几步：

1. 在商家面板复制导入地址；
2. 客户端里找「配置」「订阅」或「添加」入口；
3. 选择“从链接导入”，粘贴订阅地址；
4. 更新订阅，确认节点列表出现；
5. 选节点，点击连接，系统会弹出 VPN 权限确认，允许即可；
6. 打开浏览器验证。

## 手机上常见问题

| 现象 | 优先检查 |
| --- | --- |
| 连接后没有网 | 换节点；检查系统时间是否自动同步 |
| 过一会儿自动断开 | 省电策略杀后台；iOS 检查是否允许后台刷新 |
| 耗电明显 | 关闭不必要的规则更新频率；减少全局代理 |
| 部分应用不走代理 | 看客户端是否支持按应用分流或 TUN 模式 |

## 别忘了流量是共用的

手机和电脑用同一个订阅时，流量共用。手机上视频、应用更新和系统后台流量都可能消耗额度，建议在面板里留意每日用量，必要时用规则让国内流量直连。

## 手机端先确认服务与客户端是两件事

购买网络服务得到的是账户权益与配置入口，客户端则负责读取配置并在设备上建立连接。两者可能由不同开发者提供，费用也可能分开。某个客户端收费，不代表其中自动包含机场套餐；商家提供配置，也不代表它能够兼容所有手机软件。

开始选择前记下手机系统、系统版本和商家支持格式，再查看客户端当前说明。不要仅凭应用图标或名称相似就下载安装，也不要从陌生群聊获取所谓特别版。处理网络配置的软件需要可信来源，省下的一点下载步骤不值得换成无法确认的安装包。

## 苹果设备要考虑账户与更新方式

先查看应用是否在自己的正常商店账户中可用、是否支持当前系统，以及购买与更新如何处理。不要为了安装而购买他人的共享账户，或把自己的商店密码交给陌生人。软件取得方式不清楚时，后续更新和恢复同样会成为问题。

导入配置后先验证最小流程，不急于套用大量网络规则。若商家教程展示的界面与当前版本不同，应查对应版本说明，按功能含义寻找入口。不同应用的规则语法和配置扩展可能不同，不能因为都能读取节点就假设所有规则都可互换。

## 安卓设备要留意后台与电量管理

手机息屏后、切换应用后或从无线网络切到移动数据后，连接表现可能变化。测试时应覆盖这些日常动作，而不是只在刚打开应用的几十秒内确认可用。涉及后台运行权限时，按系统与软件官方说明设置，不盲目关闭全部安全与电量管理功能。

也要留意设备里是否已有其他使用系统网络连接能力的应用。多个工具的运行方式可能互相影响，出现异常时先识别当前谁在控制连接。不要同时安装多款陌生客户端，通过反复开关碰运气解决问题。

## 无线网络与移动数据分别验收

家里无线网络正常，不代表通勤时移动数据也一样。可以在有权限使用的目标服务上做一次轻量操作，观察切换网络后是否恢复、是否需要手动重连。测试不会证明所有地方都稳定，但能发现自己最常遇到的切换问题。

移动数据还涉及运营商套餐与机场额度两笔计量。通过移动网络传输，通常不会因为购买了机场套餐而免除本地移动流量消耗。对大文件与视频任务，应同时关注两边用量，不把其中一个面板的剩余额度当作全部预算。

## 换手机之前保存恢复路径

记住服务商正式登录入口和账户恢复方式，保留必要订单信息，不只依赖旧手机里的一张配置。迁移时先在新设备验证，再清理旧设备；旧配置包含敏感标识，不应跟随二手手机转交他人。

如果怀疑配置泄露，应按商家方式重置并更新正在使用的设备。客户端备份也可能包含凭据，存放时应限制访问。真正适合你的手机客户端，应让日常连接、更新和恢复都容易理解，而不是只有首次导入时看起来简单。
