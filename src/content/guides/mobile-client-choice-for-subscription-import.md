电脑端有[现成的导入教程](/guides/clash-verge-rev-import-subscription-tutorial/)，手机端不一样：客户端更多，上架状态变得快，有的在你所在地区的商店根本搜不到。所以这篇不替你背书某一款软件，而是给出一套**怎么挑**的标准。

## 选客户端的 5 条标准

| 标准 | 为什么重要 | 怎么核对 |
| --- | --- | --- |
| 官方来源 | 客户端处理你全部网络流量 | 从项目官方页面或开发者官方渠道进入，不用第三方打包 |
| 支持订阅格式 | 不支持就读不出节点 | 商家教程页会写支持的格式，对照客户端说明 |
| 持续更新 | 协议和内核在变，长期不更新的软件会逐渐失效 | 看项目最近一次更新时间 |
| 规则分流 | 决定国内外流量能不能自动区分 | 看是否支持规则和规则集 |
| 耗电与后台稳定性 | 手机后台常被系统杀掉 | 看使用反馈，自己用一天检验 |

## iOS 的选择流程

1. 先查看你的账号所在地区，在应用商店里能搜到哪些相关客户端；
2. 按上面的 5 条标准筛选，不要因为名字熟就下载；
3. 注意不同客户端的付费方式，是一次性买断还是订阅制，下单前看清楚；
4. 在商家的使用教程页查找是否列出推荐的 iOS 客户端，优先看列出来的。

iOS 对后台网络扩展有系统限制，不同客户端的省电表现不同，需要自己试用观察。

## 安卓的选择流程

1. 先看商家教程推荐了哪些客户端；
2. 打开项目官方发布页，看最近更新时间和发布说明；
3. 下载与你设备架构匹配的安装包，通常是 arm64；
4. 安装后给予 VPN 连接权限，并把应用加入省电白名单，防止被后台清理。

## 导入订阅的通用步骤

不论哪个客户端，基本都是这几步：

1. 在商家面板复制导入地址；
2. 客户端里找「配置」「订阅」或「添加」入口；
3. 选择“从链接导入”，粘贴订阅地址；
4. 更新订阅，确认节点列表出现；
5. 选节点，点击连接，系统会弹出 VPN 权限确认，允许即可；
6. 打开浏览器验证。

## 手机上常见问题

| 现象 | 优先检查 |
| --- | --- |
| 连接后没有网 | 换节点；检查系统时间是否自动同步 |
| 过一会儿自动断开 | 省电策略杀后台；iOS 检查是否允许后台刷新 |
| 耗电明显 | 关闭不必要的规则更新频率；减少全局代理 |
| 部分应用不走代理 | 看客户端是否支持按应用分流或 TUN 模式 |

## 别忘了流量是共用的

手机和电脑用同一个订阅时，流量共用。手机上视频、应用更新和系统后台流量都可能消耗额度，建议在面板里留意每日用量，必要时用规则让国内流量直连。
